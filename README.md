# Phyllary

Phyllary is a workflow-verb facade over existing project primitives. It keeps
deterministic workflow mechanics in one command boundary while people and agents
keep the judgment: choose and author the work; Phyllary captures, claims,
reconciles, and hands it off.

Run it from a checkout:

```sh
bin/phyllary doctor
```

Or install the stdlib-only Python package:

```sh
python -m pip install .
phyllary doctor
```

See [CONTEXT.md](CONTEXT.md) for its vocabulary and
[docs/adr](docs/adr) for its public contract.
